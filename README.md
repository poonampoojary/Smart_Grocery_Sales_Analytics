🛒 Smart Grocery Sales Analytics

📌 Project Overview

Smart Grocery Sales Analytics is a data analytics project designed to analyze grocery sales, product performance, revenue, and inventory trends.

The project uses Python, SQLite, and Power BI to clean, process, store, and visualize grocery sales data through an interactive dashboard.

🎯 Objectives

* Analyze total grocery sales and revenue.
* Identify top-performing products.
* Understand product category performance.
* Analyze daily sales and quantity trends.
* Monitor inventory and stock-related information.
* Present meaningful business insights through visualizations.

🛠️ Technologies Used

* Python – Data cleaning and processing.
* Pandas – Data manipulation and analysis.
* SQLite – Database management.
* Microsoft Excel – Data handling.
* Power BI – Interactive dashboard and visualization.
* CSV – Data storage and export.

⚙️ Project Workflow

1. Data Collection: Grocery sales data is collected and prepared for analysis.
2. Data Cleaning: Python is used to clean and process the raw dataset.
3. Database Management: Cleaned sales data is stored in an SQLite database.
4. Data Export: Processed data is exported into CSV format.
5. Data Visualization: Power BI is used to create an interactive dashboard.
6. Business Insights: Sales, revenue, quantity, and product performance are analyzed.

📊 Dashboard Features

* Total Revenue Analysis
* Total Quantity Analysis
* Average Revenue
* Product Category Analysis
* Inventory and Stock Analysis
* Product Performance Analysis
* Sales Trend Visualization
* Category-wise Revenue Comparison

💡 Key Outcomes

* Provides insights into sales and inventory trends.
